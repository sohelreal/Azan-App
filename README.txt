1. Create a free account at github.com and make a new repository (e.g. "azan").
2. Click "uploading an existing file" and drag in EVERYTHING from this folder
   (including the .github folder), then Commit.
3. Open the Actions tab -> "Build APK" -> wait about 5 minutes for the green tick.
4. Open the finished run, download "azan-apk" (a zip), unzip it to get app-debug.apk.
5. Copy the APK to your Android phone and tap it. Allow "install unknown apps" if asked.
